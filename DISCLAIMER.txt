4. 关于加密密钥与校验值的特别说明 / On Keys and Checksums
--------------------------------------------------------------------------------

★ 本仓库【不发布】任何可直接用于解密 Sony 固件的密钥值。
   文档中描述的是：密钥的用途、长度、在包结构中的对应关系、解密流程，
   但具体密钥字节不在本仓库内。

★ 本仓库【不发布】任何可用于伪造官方固件的签名或校验材料。

本仓库确实记录了完整性校验的算法性质（例如某处使用标准 CRC-32、
覆盖范围为包体的哪个区间、结果以何种字节序存放）。这类信息属于
**格式与算法描述**，不包含密钥，也不构成绕过手段。

如果你需要执行解密，请：
  (i)  使用你自己合法持有的设备与固件；
  (ii) 自行取得所需密钥；
  (iii) 在本地完成全部操作，不要上传固件或密钥。

This repository does NOT publish any key values usable to decrypt Sony
firmware. Documentation describes key purpose, length, position within the
package structure and the decryption flow — but not the key bytes.

This repository does NOT publish signing or verification material usable to
forge official firmware.

This repository DOES NOT provide an end-to-end repacking implementation or
step-by-step firmware modification procedure. Only structural descriptions,
failure modes and read-only verification tooling are published. The repacking
path was explored and round-trip verified in a controlled setting, but the
tooling is deliberately withheld because a ready-to-run implementation would
convert research findings into a turnkey ability to produce flashable modified
firmware, and failure of such firmware is irreversible.

本仓库**不提供**端到端的重打包实现，也不提供分步的固件修改操作流程。
只发布结构描述、失效模式与只读校验工具。回打包路径在受控条件下做过往返验证，
但工具刻意不公开 —— 因为一个能跑的实现会把"研究结论"变成
"端到端产出可刷写修改固件"的能力，而这类固件刷入失败是不可逆的。

Integrity-check *algorithm properties* (e.g. that a standard CRC-32 is used,
which byte range it covers, and its byte order) are documented as format
description. These contain no keys and provide no circumvention means.

If you need to decrypt, use your own lawfully held device and firmware,
obtain the required keys yourself, and perform all operations locally.
Do not upload firmware or keys.

5. 关于逆向工程分析的边界 / Scope of Reverse-Engineering Analysis
--------------------------------------------------------------------------------

本项目对 Sony 二进制进行了静态分析以理解其结构与机制。发布时遵循：

  - 只公开**结论与机制描述**（类名、函数名、调用关系、数据结构语义、
    状态值含义），不公开完整反汇编/伪代码导出；
  - 必要时引用**极少量**反汇编片段用于说明具体机制，属互操作性研究中的
    合理引用，不构成对原作品的替代；
  - 不公开 Sony 的私有文件内容，只描述其格式。

This project performs static analysis of Sony binaries to understand
structure and mechanisms. Publication follows these rules: only conclusions
and mechanism descriptions are published (class/function names, call
relations, data-structure semantics, state-value meanings); complete
disassembly or pseudocode exports are not; a very small number of
disassembly fragments may be quoted to explain a specific mechanism, as
fair quotation for interoperability research; Sony's private file contents
are not published, only their formats described.
